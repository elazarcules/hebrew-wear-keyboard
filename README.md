# מקלדת עברית ל-Wear OS

מקלדת עברית ל-Pixel Watch ולשעוני Wear OS עגולים.

- הפריסה הישראלית הרגילה, בלי אותיות סופיות: 22 מקשים בשלוש שורות.
- אותיות סופיות נוצרות לבד בסוף מילה (אחרי רווח, Enter או סימן פיסוק). לחיצה ארוכה על כ מ נ פ צ נותנת את הצורה הסופית ידנית.
- המקשים 123 / אבג עוברים בין אותיות למספרים וסימנים. 🌐 עובר למקלדת הבאה (למשל Gboard, בשביל אנגלית). לחיצה ארוכה על ⌫ מוחקת ברצף.
- רוחב השורות מחושב לפי צורת המסך העגול, כך שהמקשים לא נחתכים בקצוות.

## התקנה (Fedora)

```bash
sudo dnf install android-tools
```

בשעון: הגדרות ← מערכת ← מידע ← גרסאות, ולהקיש 7 פעמים על "מספר Build".
אחר כך: הגדרות ← אפשרויות למפתחים ← להפעיל "ניפוי באגים ב-ADB" ו"ניפוי באגים אלחוטי".
השעון והמחשב צריכים להיות על אותה רשת Wi-Fi.

צימוד, פעם אחת בלבד (בשעון: ניפוי באגים אלחוטי ← "צימוד מכשיר חדש"):

```bash
adb pair <ip>:<pairing-port>     # להזין את הקוד בן 6 הספרות
adb connect <ip>:<port>
```

התקנה ועדכון:

```bash
./install.sh                     # מוריד את הגרסה האחרונה (צריך gh מחובר)
./install.sh ~/Downloads/hebrew-keyboard.apk
```

הסקריפט מתקין את המקלדת, מפעיל אותה ומגדיר אותה כברירת מחדל.

## בנייה

כל push ל-`main` בונה APK ב-GitHub Actions ומפרסם אותו בגרסה בשם `latest`.

ה-keystore שב-`keystore/` הוא מפתח debug, ונשמר בריפו בכוונה: כך לכל הגרסאות יש אותה חתימה, ו-`adb install -r` מעדכן את האפליקציה בלי להסיר אותה קודם.
